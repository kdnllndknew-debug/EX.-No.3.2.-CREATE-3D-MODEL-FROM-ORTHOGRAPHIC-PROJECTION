## DATE:
## AIM:
To create a 3D model from given orthographic projection.

## REQUIREMENTS:
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:
1.	Open new file and then select sketch icon.
2.	Select the plane for sketching. 
3.	After finishing the sketch use finish sketch option to finalize the sketch.
4.	Use sketching features (line, circle, arc, rectangle, polygon, etc.,) to draw the given sketch.

<img width="385" height="807" alt="image" src="https://github.com/user-attachments/assets/b1646b45-fb06-45ce-a29d-3f67b42def38" />


5.	Use sketch modifying features (cut, trim, mirror, move, etc.,) to edit the sketch.

<img width="232" height="706" alt="image" src="https://github.com/user-attachments/assets/961b4b2b-1817-4a7c-8bb6-eca5ce338b44" />


6.	Use inspect feature to measure the dimensions of sketch.

<img width="295" height="553" alt="image" src="https://github.com/user-attachments/assets/c3380153-06d3-436c-bbd4-dcf74b7673ca" />

7.	After finishing the sketch use finish sketch option to finalize the sketch.
